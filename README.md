Meus Projetos
Este repositório reúne os projetos em que estou trabalhando e que fazem parte do meu aprendizado e desenvolvimento prático.

Aqui estão aplicações e experimentos construídos com diferentes tecnologias, mantidos em evolução conforme novas funcionalidades, melhorias e conhecimentos são adicionados.

Projetos
ProjetoDeFilmes (CineScope) — catálogo de filmes full stack construído com ASP.NET Core, C# (.NET 10) e SQLite, com front-end em HTML, CSS e JavaScript puros. Busca tolerante a acentos e maiúsculas, filtros por gênero, ordenação e paginação, com a API e o site servidos pela mesma aplicação.
Senai/ControleLab — MVP de sistema web para controle de empréstimos e devoluções de ferramentas e equipamentos em laboratórios escolares. Back-end em Node.js + Express, banco MySQL e API REST em JSON; front-end em HTML, Tailwind CSS e JavaScript. Inclui cadastro de ferramentas, controle de disponibilidade, empréstimo/devolução com responsável e painel com indicadores.
Conicas — visualizador 3D interativo da elipse como seção cônica, em C# (.NET 8) com Raylib-cs. Mostra o cone duplo cortado por um plano e a elipse da interseção, com um campo onde se digita a equação (ex.: x²/25 + y²/9 = 1) ou os semieixos; entradas inválidas são sinalizadas com mensagem de erro.
Os projetos deste repositório estão em desenvolvimento e podem receber alterações frequentes.
