# Meus Projetos

Este repositório reúne os projetos em que estou trabalhando e que fazem parte do
meu aprendizado e desenvolvimento prático.

Aqui estão aplicações e experimentos construídos com diferentes tecnologias,
mantidos em evolução conforme novas funcionalidades, melhorias e conhecimentos
são adicionados.

## Projetos

- **ProjetoDeFilmes** — catálogo de filmes desenvolvido com Python, SQLite,
  HTML, CSS e JavaScript.
- **Fortis** — aplicação web voltada para acompanhamento de treinos, dietas e
  evolução de alunos.

> Os projetos deste repositório estão em desenvolvimento e podem receber
> alterações frequentes.
